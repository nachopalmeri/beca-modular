# Beca Modular — audiovisual direction and production

Date: 2026-10-28. Purpose: explain the product thesis, local simulation, and conditional roadmap to a hackathon juror in three short Spanish videos.

## Creative brief

- **Audience/job:** a juror or prospective sponsor should understand the proposed money flow, who decides, what is synthetic, and what must be validated.
- **Truth/constraint:** this is a proposal plus an in-memory simulation. No live institution, academic validation, AI inference, payment, or measured educational impact is shown.
- **Signature:** a visible fund moves through a modular path; a human-review gate sits between an AI suggestion and a release. The graphic encodes the product rule instead of using generic stock footage.
- **System:** existing forest/cream/rust palette; Georgia for editorial headlines, sans-serif for narration captions, monospace for labels and state. 16:9 frame, restrained light, ambient score, Spanish system narration and selectable/burned-in captions.
- **Accessibility/performance:** no autoplay; native controls; downloadable MP4; WebVTT captions and full text transcripts; responsive player; the video itself is static encoded media and does not run animation on the visitor's device.

## Reference directions and rejected treatment

1. **The Pudding** (documented in `docs/ux-redesign.md`): reveal a claim alongside the graphic that supports it. Borrow the sentence-by-sentence visual progression; reject an endless scroll story inside the video.
2. **Our World in Data** (documented in `docs/ux-redesign.md`): keep labels, definitions, units and caveats attached to the quantities. Borrow explicit labels for synthetic units; reject presenting any invented value as research.
3. **Beca Modular's existing design language** (the current landing and product route): warm paper, forest green, rust and serif/sans contrast. Borrow the system itself; reject the older generic dark promo footage and garbled in-frame interface text.

### Storyboard

- `historia`: thesis → sponsor-defined cap → milestone/institution → human review → visible ledger → validation caveat.
- `recorrido`: set budget → freeze rules → synthetic evidence → AI suggestion → tutor decision → simulated ledger/QR disclaimer.
- `roadmap`: available prototype → deterministic no-key AI → user validation → production blockers → authorized small pilot → no promised dates/impact.

## Source and regeneration

- Copy/story source: `scripts/presentation-videos.json`.
- Original 1920×1080 Canvas graphics: `scripts/presentation-renderer.html`.
- Local Spanish narration: `scripts/render-presentation-audio.ps1` (Microsoft Sabina Desktop voice; no cloud TTS request).
- Render/encode pipeline: `scripts/render-presentation-videos.mjs` (Chrome + installed Playwright; FFmpeg H.264/AAC, MP4 subtitle track, WebVTT and JPG poster).
- Outputs: `assets/presentaciones/{historia,recorrido,roadmap}.{mp4,vtt}` plus posters; mirror under `dist/assets/presentaciones/`.
- Regenerate on the current Windows authoring environment: `node scripts/render-presentation-videos.mjs`. Requires FFmpeg, Chrome, Node and the already available Playwright runtime. No dependencies are installed.
- Web player: `presentacion.html`; source/dist/offline archive should be synchronized after a rerender.

## Claims and limitations

All figures shown in the graphics are explicitly illustrative or ledger examples; none is sourced as observed scholarship data. The system voice is synthetic narration, not a participant testimonial. Graphics are authored from Canvas primitives, not generated by Higgsfield. A real external video-generation service was not available or invoked. The film does not demonstrate a real payment, a real evidence file, OCR on a real document, a model inference, user demand, or educational outcomes.
